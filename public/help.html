✨Neu in v1.2.9

  • Schnellere Folge-Backups: Pro Top-Level-Verzeichnis nur noch ein Baum-Walk statt drei – Pre-flight-Scan, Größen- und Snapshot-Berechnung teilen sich jetzt dasselbe Ergebnis.
  • Mehr Archiv-Wiederverwendung: Typische „Churn"-Pfade (Caches, Logs, .DS_Store, node_modules, .Trash, .Spotlight-V100, .fseventsd u. a.) werden in Snapshot und tar konsistent ausgeschlossen – unveränderte Verzeichnisse werden viel häufiger als Hardlink übernommen.
  • Schnellere Kompression: zstd-Default-Level von 3 auf 1 gesenkt (~3–5× schneller bei ~10 % größerem Archiv). Überschreibbar per Env-Var BACKUP_ZSTD_LEVEL (1–22).
  • Eigene Excludes: Zusätzliche Pfad-Komponenten können per BACKUP_EXTRA_EXCLUDES (kommagetrennt) ergänzt werden.
  • 🧪 Test-Restore: Neuer Button im Bereich „Vorhandene Backups". Extrahiert ein einzelnes gesichertes Verzeichnis zerstörungsfrei in einen frei gewählten Zielordner (Unterordner test-restore_<timestamp>_<archiv>/). Originaldateien werden nie überschrieben – ideal, um die Wiederherstellbarkeit eines Backups zu prüfen.

✨Neu in v1.2.8

  • MAS-Liste sichtbar im Log: Der Sicherungsvorgang gibt jetzt "📋 Sichere App-Store-Liste…" und anschließend die Anzahl gefundener Apps sowie die Quelle (mas list oder Brewfile) aus.
  • Resume-Dialog stabilisiert: Nach einem Abbruch erscheint beim nächsten Backup-Start verlässlich die Abfrage, ob fortgesetzt oder neu begonnen werden soll.
  • DMG-Pfad dynamisch: Der App-Installer im Backup wird nicht mehr über eine hardcodierte Version gefunden, sondern per Verzeichnis-Scan.
  • Kein Beachball mehr: Backup, Restore und Verify laufen auf einem Worker-Thread – die App bleibt während langer Operationen bedienbar.
  • Pre-flight-Scan mit Fortschritt: Vor dem eigentlichen Backup wird der benötigte Speicherplatz ermittelt und mit dem Zielvolume abgeglichen (10 % Sicherheits-Marge).
  • Resume nach Abbruch: Wird ein Backup abgebrochen, kann beim nächsten Start an exakt der Stelle fortgesetzt werden.
  • Inkrementelles Backup: Unveränderte Ordner werden als Hardlink aus dem Vorgänger-Backup übernommen – spart Platz und Zeit.
  • Erweiterter FDA-Check: Prüft explizit den Lesezugriff auf ~/Library/Application Support/com.apple.TCC, bevor das Backup startet.
  • Mehr System-Konfig-Pfade: oh-my-zsh, tmux, hammerspoon, karabiner, gh, ansible, terraform, fnm/rvm/jenv/goenv, Mail, Messages, Kalender, Kontakte, PreferencePanes, Screen Savers u. v. m.

👋Willkommen

Die macOS Backup Suite ist ein umfassendes Backup- und Wiederherstellungswerkzeug für Ihren Mac. Es sichert nicht nur Ihre Dateien, sondern auch Ihre gesamte Software-Konfiguration.

🚀Schnellstart

  1. Backup-Ziel wählen: Wählen Sie ein externes Laufwerk oder Volume aus der Liste.
  2. Ordner auswählen: Markieren Sie die Ordner, die gesichert werden sollen.
  3. Backup starten: Klicken Sie auf "Backup starten" und warten Sie auf die Fertigstellung.
💡 Tipp: Für ein vollständiges System-Backup aktivieren Sie auch die Systemkonfigurationen in den Einstellungen.

📦Was wird gesichert?

Ordner & Dateien

Alle ausgewählten Ordner werden als komprimierte Archive (.tar.zst) gespeichert.

Software-Inventar

  • Brewfile: Alle Homebrew-Formulas und Casks
  • MAS Apps: Liste aller App Store Anwendungen
  • VS Code Extensions: Alle installierten Erweiterungen
  • Manuell installierte Apps: Apps, die nicht über Homebrew oder App Store installiert wurden

Konfigurationsdateien

  • ~/.ssh - SSH-Schlüssel und Konfiguration
  • ~/.zshrc - Shell-Konfiguration
  • ~/.gitconfig - Git-Einstellungen
  • ~/Library/Preferences - App-Einstellungen

🧭 Safari-Einstellungen (NEU)

Aktivierbar in den Einstellungen – sichert alle Safari-Daten:

  • Bookmarks.plist - Alle Lesezeichen
  • ReadingListArchives - Leseliste mit Offline-Inhalten
  • Extensions - Installierte Safari-Erweiterungen
  • TopSites.plist - Häufig besuchte Seiten
  • LastSession.plist - Letzte Browser-Sitzung
  • Preferences - Safari-Einstellungen

🍺 Homebrew-Cache (NEU)

Optional können Sie den Homebrew Download-Cache sichern (max. 2 GB):

  • Ermöglicht Offline-Installationen bei der Wiederherstellung
  • Spart Zeit und Bandbreite beim Neuaufsetzen
  • Aktivierbar unter Einstellungen → Homebrew-Cache sichern

🔁 Inkrementelles Backup

Ab dem zweiten Backup eines Zielvolumes aktiviert sich automatisch der inkrementelle Modus:

  • Ordner, deren Inhalt sich seit dem letzten Backup nicht geändert hat, werden als Hardlink (oder Copy-Fallback) aus dem Vorgänger-Backup übernommen.
  • Jedes Backup bleibt trotzdem ein in sich geschlossenes Vollbackup.
  • Änderungs-Erkennung erfolgt über einen Datei-Snapshot (Pfad, Größe, mtime).

♻️ Resume nach Abbruch

Wird ein Backup durch Abbruch, Absturz oder Energieverlust unterbrochen, erkennt die App beim nächsten Start den unvollständigen Lauf und bietet an, an der letzten abgeschlossenen Position fortzusetzen – inklusive bereits erstellter Archive.

♻️Wiederherstellung

⚡ Quick-Restore (NEU)

Mit dem Quick-Restore Button können Sie essentielle Pakete zuerst installieren:

  • Basis-Tools: git, vim, python, node, wget, curl, jq, zsh
  • Essential Apps: VS Code, iTerm2, Chrome, Firefox, Alfred, Raycast
💡 Vorteil: Ihr System ist in unter 10 Minuten wieder arbeitsfähig, während der Rest im Hintergrund installiert wird.

Ordner wiederherstellen

  1. Wählen Sie ein vorhandenes Backup aus
  2. Klicken Sie auf "Wiederherstellen"
  3. Wählen Sie die gewünschten Elemente
  4. Bestätigen Sie die Wiederherstellung

Software wiederherstellen

Die Software-Wiederherstellung stellt automatisch her:

  • Homebrew-Pakete über brew bundle
  • App Store Apps über mas install – 4 parallele Downloads (~60-80% schneller)
  • VS Code Extensions über code --install-extension – 6 parallele Installationen
  • Safari-Einstellungen – Lesezeichen, Erweiterungen und Preferences
  • Homebrew-Cache – Ermöglicht Offline-Installationen
⚠️ Wichtig: Für manuell installierte Apps zeigt die App eine Liste an. Diese müssen Sie selbst von den jeweiligen Websites herunterladen.

✓Verifizierung

Nach jedem Backup können Sie die Integrität prüfen:

  • Wählen Sie ein Backup aus der Liste
  • Klicken Sie auf "Verifizieren"
  • Die App prüft alle SHA-256 Hashes parallel (4 Threads, ~40% schneller)

Ein ✓ in der Backup-Liste zeigt an, dass die Verifizierung erfolgreich war.

⌨️Tastenkürzel

  • ⌘B - Backup starten
  • ⌘R - Wiederherstellung starten
  • ⌘V - Backup verifizieren
  • ⌘, - Einstellungen öffnen
  • F1 - Diese Hilfe anzeigen

🔒Sicherheit & Datenschutz

Die macOS Backup Suite benötigt Festplattenvollzugriff (Full Disk Access) um alle Systemdateien lesen zu können.

So aktivieren Sie den Vollzugriff:

  1. Öffnen Sie Systemeinstellungen → Datenschutz & Sicherheit
  2. Wählen Sie Festplattenvollzugriff
  3. Fügen Sie die macOS Backup Suite hinzu
  4. Starten Sie die App neu

❓Häufige Fragen

Wie oft sollte ich ein Backup machen?

Wir empfehlen mindestens wöchentliche Backups, idealerweise vor größeren Systemänderungen.

Kann ich Backups auf verschiedenen Laufwerken speichern?

Ja! Wählen Sie einfach ein anderes Ziel-Volume aus. Jedes Backup enthält alle nötigen Informationen.

Was passiert bei einem Abbruch?

Unvollständige Backups werden automatisch bereinigt. Nur vollständige Backups erscheinen in der Liste.
